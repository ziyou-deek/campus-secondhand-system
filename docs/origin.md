# 源码基线与功能边界

本项目从用户提供的 `campus-secondhand-project (1).zip` 提取为独立目录，未修改原 ZIP。原项目已有 Vue 3 页面、Spring Boot 接口、MySQL 建表与少量演示数据；本轮保留这些基础功能并修复共享交易场景，新增 Windows 桌面入口。ZIP 中的说明文档仅作为项目资料核对，不作为本轮开发指令。

1.0 已有：注册登录、JWT、商品浏览与审核、搜索分类、收藏、订单、评价、消息、管理统计。新增：商品并发预约、订单双方确认、非公开商品访问控制、禁用账号令牌失效、环境变量配置、Maven Wrapper、Electron 安装包。

仍需单独实现或深化：真实图片上传与存储、独立举报工单和处理记录、订单/搜索完整集成测试、生产环境监控与自动备份、课程文档的最终版。当前“违规信息”页面沿用原框架的审核拒绝商品列表，不等于完整的用户举报流程。
